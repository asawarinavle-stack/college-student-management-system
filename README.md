# 🎓 College Student Management System (Kubernetes Demo)

A simple Python-based web application containerized with Docker and deployed using Kubernetes.

---

## 📌 Features

- Add new students
- Update student details
- Delete student records
- View all students
- Simple REST/web-based interface

---

## 🛠️ Tech Stack

- Backend: Python (Flask or similar – check app.py)
- Containerization: Docker
- Orchestration: Kubernetes
- Config: YAML (pod.yaml)
